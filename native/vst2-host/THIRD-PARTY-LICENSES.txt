ABI reference: RustAudio/vst-rs
https://github.com/RustAudio/vst-rs
https://github.com/RustAudio/vst-rs/blob/master/LICENSE

The VST2 ABI declarations were checked against the published RustAudio definitions.
No Steinberg SDK headers or deprecated vst-rs host implementation are bundled.

Linux editor ABI references (protocol facts only; no source copied):
https://github.com/juce-framework/JUCE/blob/master/modules/juce_audio_processors/format_types/juce_VSTPluginFormat.cpp
https://github.com/juce-framework/JUCE/blob/master/modules/juce_audio_plugin_client/juce_audio_plugin_client_VST2.cpp
https://github.com/DISTRHO/DPF/blob/main/distrho/src/DistrhoPluginVST2.cpp
https://github.com/Ardour/ardour/blob/master/gtk2_ardour/linux_vst_gui_support.cc

The modern JUCE/DPF ABI uses effEditOpen.ptr = numeric X11 Window ID and value = 0.
Ardour's older shared Display*/_XEventProc extension is outside this host's supported ABI.

Shell/container ABI references (protocol facts only; no source copied):
https://github.com/RustAudio/vst-rs/blob/master/src/host.rs
https://github.com/RustAudio/vst-rs/blob/master/src/plugin.rs
https://github.com/juce-framework/JUCE/blob/master/modules/juce_audio_processors_headless/format_types/juce_VSTPluginFormatHeadless.cpp
https://github.com/juce-framework/JUCE/blob/master/modules/juce_audio_processors_headless/format_types/juce_VSTPluginFormatImpl.h

effShellGetNextPlugin (70) enumerates child IDs/names, terminating with ID zero.
audioMasterCurrentId (2) selects the child before VSTPluginMain returns. This host scopes
that selection to the current instance/native call instead of a process-wide global.
